Mobile Device Features: Camera, GPS & Permissions

Build a Location Journal app that captures photographs, reads GPS coordinates with permission, and saves journal entries on the device.

Duration: 1 week   |   Prerequisites: React Native components, state, basic navigation, and asynchronous JavaScript

1. Learning Objectives

By the end of this module, students will be able to:

  1. Explain how Expo exposes device hardware capabilities to React Native apps.
  2. Install and configure camera, location, and local storage libraries.
  3. Request camera and foreground-location permissions and respond to denial.
  4. Capture a photograph and display its URI.
  5. Retrieve GPS latitude and longitude and handle loading/error states.
  6. Persist and restore journal entries using AsyncStorage.
  7. Discuss privacy, consent, and responsible handling of location data.

3. Project Setup

Install Node.js LTS and Visual Studio Code. Install Expo Go on a compatible physical phone, or configure an Android/iOS simulator. In the VS Code terminal:

npx create-expo-app@latest LocationJournal --template blank
cd LocationJournal
npx expo install expo-camera expo-location expo-file-system @react-native-async-storage/async-storage
npx expo start

Open the project in VS Code. Replace App.js with the tutorial below. Scan the Expo QR code or launch a simulator.

Important: Test camera and GPS behavior on a real device where possible. Simulators may have simulated location and camera limitations. Always request permission before accessing sensitive device features.

4. Step-by-Step Coding Tutorial

Part A: Camera permission and photo capture

useCameraPermissions provides the current permission state and a function to request permission. CameraView displays the preview; its ref lets you capture a photo.

import { CameraView, useCameraPermissions } from 'expo-camera';
import { useRef, useState } from 'react';
import { Button, Image, Text, View } from 'react-native';

function CameraExample() {
  const cameraRef = useRef(null);
  const [permission, requestPermission] = useCameraPermissions();
  const [photo, setPhoto] = useState(null);

  if (!permission) return <Text>Checking camera permission...</Text>;
  if (!permission.granted) {
    return <View>
      <Text>Camera access is needed to take a journal photo.</Text>
      <Button title="Allow camera" onPress={requestPermission} />
    </View>;
  }
  async function capture() {
    const result = await cameraRef.current?.takePictureAsync();
    if (result?.uri) setPhoto(result.uri);
  }
  return <View>
    <CameraView ref={cameraRef} style={{ height: 260 }} facing="back" />
    <Button title="Take Photo" onPress={capture} />
    {photo && <Image source={{ uri: photo }} style={{ height: 180 }} />}
  </View>;
}

Part B: Request GPS location

Request foreground location permission only when the student taps a button. Do not collect background location for this assignment.

import * as Location from 'expo-location';

async function getCoordinates() {
  const { status } = await Location.requestForegroundPermissionsAsync();
  if (status !== 'granted') {
    throw new Error('Location permission was denied.');
  }
  const position = await Location.getCurrentPositionAsync({
    accuracy: Location.Accuracy.Balanced,
  });
  return {
    latitude: position.coords.latitude,
    longitude: position.coords.longitude,
  };
}

Part C: Save journal data locally

AsyncStorage stores strings. Convert JavaScript objects into JSON before saving and parse them when loading.

import AsyncStorage from '@react-native-async-storage/async-storage';

const STORAGE_KEY = '@location_journal_entries';

async function saveEntries(entries) {
  await AsyncStorage.setItem(STORAGE_KEY, JSON.stringify(entries));
}

async function loadEntries() {
  const raw = await AsyncStorage.getItem(STORAGE_KEY);
  return raw ? JSON.parse(raw) : [];
}

Part D: Complete working App.js

This example combines permission requests, photo capture, GPS lookup, timestamped entries, image persistence, and local storage. The image is copied into the app's document directory so that saved entries do not rely on temporary camera files.

import React, { useEffect, useRef, useState } from 'react';
import {
  Alert, Button, FlatList, Image, SafeAreaView,
  StyleSheet, Text, TextInput, View,
} from 'react-native';
import { CameraView, useCameraPermissions } from 'expo-camera';
import * as Location from 'expo-location';
import * as FileSystem from 'expo-file-system';
import AsyncStorage from '@react-native-async-storage/async-storage';

const KEY = '@location_journal_entries';

export default function App() {
  const camera = useRef(null);
  const [permission, requestPermission] = useCameraPermissions();
  const [showCamera, setShowCamera] = useState(false);
  const [photoUri, setPhotoUri] = useState(null);
  const [coords, setCoords] = useState(null);
  const [note, setNote] = useState('');
  const [entries, setEntries] = useState([]);
  const [busy, setBusy] = useState(false);

  useEffect(() => {
    AsyncStorage.getItem(KEY)
      .then(raw => { if (raw) setEntries(JSON.parse(raw)); })
      .catch(() => Alert.alert('Error', 'Could not load journal.'));
  }, []);

  async function takePhoto() {
    try {
      const result = await camera.current?.takePictureAsync();
      if (result?.uri) {
        setPhotoUri(result.uri);
        setShowCamera(false);
      }
    } catch {
      Alert.alert('Camera error', 'Could not take a photo.');
    }
  }

  async function readLocation() {
    setBusy(true);
    try {
      const response = await Location.requestForegroundPermissionsAsync();
      if (response.status !== 'granted') {
        Alert.alert('Permission denied', 'Location access is optional.');
        return;
      }
      const result = await Location.getCurrentPositionAsync({
        accuracy: Location.Accuracy.Balanced,
      });
      setCoords({
        latitude: result.coords.latitude,
        longitude: result.coords.longitude,
      });
    } catch {
      Alert.alert('GPS error', 'Unable to determine location.');
    } finally {
      setBusy(false);
    }
  }

  async function saveJournal() {
    if (!photoUri || !coords) {
      Alert.alert('Missing data', 'Capture a photo and retrieve location.');
      return;
    }
    setBusy(true);
    let storedPhoto = null;
    try {
      const id = String(Date.now());
      // The legacy API is used explicitly for SDKs where the main
      // FileSystem.copyAsync API has been deprecated.
      const destination = FileSystem.documentDirectory + id + '.jpg';
      await FileSystem.copyAsync({ from: photoUri, to: destination });
      storedPhoto = destination;
      const entry = {
        id, note: note.trim(), photoUri: destination,
        latitude: coords.latitude,
        longitude: coords.longitude,
        timestamp: new Date().toISOString(),
      };
      const updated = [entry, ...entries];
      await AsyncStorage.setItem(KEY, JSON.stringify(updated));
      setEntries(updated);
      setPhotoUri(null);
      setCoords(null);
      setNote('');
      Alert.alert('Saved', 'Journal entry saved locally.');
    } catch {
      if (storedPhoto) {
        // Optional cleanup can remove an orphaned file on save failure.
      }
      Alert.alert('Save error', 'Could not save journal entry.');
    } finally {
      setBusy(false);
    }
  }

  return (
    <SafeAreaView style={styles.container}>
      <Text style={styles.heading}>My Location Journal</Text>
      {!permission ? (
        <Text>Checking camera permission...</Text>
      ) : showCamera && permission.granted ? (
        <View>
          <CameraView ref={camera} style={styles.camera} facing="back" />
          <Button title="Capture Photo" onPress={takePhoto} />
          <Button title="Cancel" onPress={() => setShowCamera(false)} />
        </View>
      ) : (
        <View>
          <Button title="Open Camera" onPress={async () => {
            if (permission.granted) setShowCamera(true);
            else {
              const response = await requestPermission();
              if (response.granted) setShowCamera(true);
              else Alert.alert('Camera denied', 'Enable camera in device settings.');
            }
          }} />
          {photoUri && <Image source={{ uri: photoUri }} style={styles.photo} />}
          <Button title="Get Current Location" onPress={readLocation} disabled={busy} />
          {coords && <Text>
            Latitude: {coords.latitude.toFixed(5)} | Longitude: {coords.longitude.toFixed(5)}
          </Text>}
          <TextInput
            style={styles.input} placeholder="Journal note" value={note}
            onChangeText={setNote}
          />
          <Button title="Save Entry" onPress={saveJournal} disabled={busy} />
          <Text style={styles.subheading}>Saved Entries</Text>
          <FlatList
            data={entries} keyExtractor={item => item.id}
            ListEmptyComponent={<Text>No entries yet.</Text>}
            renderItem={({ item }) => (
              <View style={styles.entry}>
                <Image source={{ uri: item.photoUri }} style={styles.thumbnail} />
                <Text>{item.note || 'Untitled entry'}</Text>
                <Text>{new Date(item.timestamp).toLocaleString()}</Text>
                <Text>{item.latitude.toFixed(5)}, {item.longitude.toFixed(5)}</Text>
              </View>
            )}
          />
        </View>
      )}
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 20, backgroundColor: '#fff' },
  heading: { fontSize: 26, fontWeight: 'bold', marginBottom: 14 },
  subheading: { fontSize: 20, fontWeight: 'bold', marginTop: 16 },
  camera: { height: 260, marginVertical: 10 },
  photo: { height: 180, marginVertical: 10 },
  input: { borderWidth: 1, borderColor: '#aaa', padding: 12, marginVertical: 12 },
  entry: { paddingVertical: 12, borderBottomWidth: 1, borderColor: '#ddd' },
  thumbnail: { width: 100, height: 80, marginBottom: 6 },
});
Expo SDK compatibility note: Some SDK versions have changed the FileSystem API. If FileSystem.copyAsync is unavailable or throws a deprecation error, change the import to import * as FileSystem from 'expo-file-system/legacy'; for this tutorial, or update to the current File/Directory API using the linked documentation. Test the example with your course's chosen Expo SDK before distributing.

Common troubleshooting

  • Camera preview blank: Verify permission and test on a physical device.
  • Location never returns: Enable device location services; use simulator mock location if needed.
  • Permission denied permanently: Open the phone's Settings app and enable access for Expo Go or the development build.
  • Photo disappears after restart: Ensure the image is copied from temporary cache to app document storage.
  • Package import fails: Run npx expo install with the package names and restart Metro.

6. Discussion Board: Mobile Privacy and User Trust

Prompt: A photo-journal app wants access to your camera and location. When should it ask for permission, and what information should it provide before requesting access? Compare two real-world apps that use camera or GPS permissions. Discuss whether they collect only the data needed for their features.

Initial post: 200–300 words. Cite at least one course resource and include one practical privacy recommendation. Peer replies: Respond substantively to two classmates (75+ words each), considering consent, data retention, or user control.

7. Homework Assignment: My Location Journal

Goal: Create a React Native / Expo mobile application that records meaningful photo-based journal entries with GPS coordinates and timestamps.

Functional requirements

  1. Create a clear home screen titled My Location Journal.
  2. Allow users to open the camera and capture a photograph.
  3. Ask for camera and foreground-location permissions at appropriate moments.
  4. Retrieve and display the current latitude and longitude.
  5. Provide a text field for a journal note.
  6. Save each entry with photo, coordinates, note, and timestamp.
  7. Display a scrollable list of saved entries.
  8. Persist saved entries and photos after the app is closed and reopened.
  9. Display helpful error messages for denied permissions and failed operations.

Submission instructions

  • Submit a GitHub repository link containing source code and a README.md with setup/run instructions.
  • Include at least three screenshots: home screen, permission/capture workflow, and saved journal list.
  • Include a 2–4 minute demonstration video showing an entry being saved and still present after reopening the app.
  • Write a 150–250 word reflection describing challenges, permission handling, and privacy decisions.
  • Do not publish real-time precise location coordinates, private addresses, or sensitive photos in your public repository or demonstration.

Optional extra credit (+5): Add an option to delete a saved entry and its stored photo after a confirmation prompt.
