Lecture: Building Your First React Native Application

1. What Is React Native?

React Native is a framework for creating mobile applications using JavaScript or TypeScript and React concepts. It allows developers to create applications for multiple platforms while sharing much of the same code.

Important: React Native is not simply a website being displayed on a phone. React Native uses native mobile interface components.

A traditional web page might contain:

<div>
  <p>Hello World</p>
</div>

A React Native application instead uses components:

<View>
  <Text>Hello World</Text>
</View>

2. Common React Native Components

Component Purpose
View A container used to organize other components.
Text Displays text on the screen.
Image Displays images.
Button Creates a basic button.
TextInput Allows users to enter information.
ScrollView Creates scrollable content.
FlatList Efficiently displays lists of information.

For this module, our primary focus will be View, Text, and StyleSheet.

3. Understanding TSX

React Native applications commonly use files ending in .tsx. TSX allows us to combine TypeScript with React component syntax. 

function App() {
  return (
    <View>
      <Text>Hello Mobile Development!</Text>
    </View>
  );
}

Breaking this down:

  • function App() defines a function named App.
  • return identifies what should appear on the screen.
  • <View> creates a container.
  • <Text> displays text.

4. Your First React Native Component

import React from 'react';
import {
  SafeAreaView,
  StyleSheet,
  Text,
  View,
} from 'react-native';

function App(): React.JSX.Element {
  return (
    <SafeAreaView style={styles.container}>
      <View>
        <Text style={styles.title}>
          My First Mobile App
        </Text>

        <Text>
          Welcome to React Native!
        </Text>
      </View>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    padding: 20,
  },

  title: {
    fontSize: 28,
    fontWeight: 'bold',
  },
});

export default App;
Think of the structure as: Component → Content → Style.

5. Understanding View

A View is one of the most commonly used React Native components. It is generally used to organize other components. 

<View>
  <Text>Student Information</Text>
  <Text>Name: John Smith</Text>
  <Text>Major: Computer Science</Text>
</View>

Views can also be nested:

<View>

  <View>
    <Text>Student Information</Text>
  </View>

  <View>
    <Text>Computer Science</Text>
  </View>

</View>

6. Understanding Text

Text displayed in a React Native application should normally be placed inside a Text component.

Correct

<Text>Hello World</Text>

Incorrect

<View>
  Hello World
</View>

7. Styling a React Native Application

React Native does not normally use traditional CSS stylesheets. Styles can instead be created using StyleSheet.create(). 

const styles = StyleSheet.create({
  title: {
    fontSize: 28,
    fontWeight: 'bold',
  },
});

Apply the style to a component:

<Text style={styles.title}>
  My Mobile App
</Text>

Web CSS

background-color: blue;
font-size: 20px;

React Native

backgroundColor: 'blue',
fontSize: 20,

Notice that React Native uses camelCase property names.

8. Common Style Properties

fontSize
Changes text size.
fontWeight
Controls text weight.
backgroundColor
Sets background color.
padding
Adds internal spacing.
margin
Adds external spacing.
borderRadius
Rounds corners.
borderWidth
Adds a border.
flex
Controls available layout space.

9. Flexbox

React Native uses Flexbox for layouts. We will explore Flexbox in more detail later, but you should recognize the following: 

container: {
  flex: 1,
  padding: 20,
}

A horizontal layout can use:

row: {
  flexDirection: 'row',
}

10. Creating Your Own Component

function Header() {
  return (
    <View>
      <Text style={styles.title}>
        Student Profile
      </Text>
    </View>
  );
}

Then use your custom component:

function App() {
  return (
    <SafeAreaView>
      <Header />
    </SafeAreaView>
  );
}
Key concept: React applications are built from small, reusable components.

11. Reusing Components

function CourseInfo() {
  return (
    <View style={styles.card}>
      <Text>Mobile Development</Text>
      <Text>Point Park University</Text>
    </View>
  );
}

You can then place the component in your application with:

<CourseInfo />

12. Basic Debugging

Common beginner errors include:

  • Missing opening or closing tags.
  • Forgetting to import a component.
  • Misspelling a component name.
  • Incorrect capitalization.
  • Missing commas or braces in styles.
When an error occurs, read the first meaningful error message in the terminal before changing code.

Part 2 — Create the Basic Profile Screen

import React from 'react';
import {
  SafeAreaView,
  StyleSheet,
  Text,
  View,
} from 'react-native';

function App(): React.JSX.Element {

  return (
    <SafeAreaView style={styles.container}>

      <Text style={styles.title}>
        Student Profile
      </Text>

      <View style={styles.card}>

        <Text style={styles.name}>
          John Smith
        </Text>

        <Text>
          Major: Computer Science
        </Text>

        <Text>
          Class: Senior
        </Text>

        <Text>
          Email: johnsmith@example.com
        </Text>

      </View>

    </SafeAreaView>
  );
}

const styles = StyleSheet.create({

  container: {
    flex: 1,
    padding: 20,
  },

  title: {
    fontSize: 30,
    fontWeight: 'bold',
    marginBottom: 20,
  },

  card: {
    padding: 20,
    borderWidth: 1,
    borderRadius: 10,
  },

  name: {
    fontSize: 22,
    fontWeight: 'bold',
    marginBottom: 10,
  },

});

export default App;
