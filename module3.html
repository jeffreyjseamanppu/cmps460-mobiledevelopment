Module Overview

In Module 3, we move beyond static mobile interfaces and begin building applications that respond to the user.

React Native applications are constructed from reusable components. Components allow developers to divide an application into smaller, manageable pieces that can be reused throughout an application.

You will also learn how data can be passed between components using props and how applications can maintain changing information using state.

By the end of this module, you will create an interactive React Native application that accepts user input, responds to button presses, updates information on the screen, and conditionally displays content.

Learning Objectives

After completing this module, you should be able to:

  • Explain the purpose of components in React Native.
  • Create functional React Native components.
  • Build reusable components.
  • Pass information between components using props.
  • Explain the difference between props and state.
  • Manage application state using the useState hook.
  • Capture user input using TextInput.
  • Respond to button presses and user events.
  • Use conditional rendering to change the user interface.
  • Build a small interactive mobile application.

Lecture: Building Interactive Mobile Applications

1. What is a Component?

Components are the building blocks of React Native applications. A component represents a portion of the user interface. 

function Welcome() {

    return (
        <View>
            <Text>Welcome to my app!</Text>
        </View>
    );

}

Large applications are typically divided into many smaller components. 

App
 |
 +-- Header
 |
 +-- UserProfile
 |
 +-- ProductCard
 |
 +-- Counter
 |
 +-- Footer

Components make applications easier to develop, test, maintain, and reuse.

2. Props

Props allow information to be passed from one component to another.

Think of props as information that is given to a component. 

function WineCard({ name, type }) {

    return (
        <View>

            <Text>{name}</Text>

            <Text>{type}</Text>

        </View>
    );

}

The component could then be used like this:

<WineCard
    name="Creekside Blanc"
    type="White Wine"
/>

The same component can now display many different wines simply by changing the props.

3. Understanding State

State represents information that can change while the application is running.

React provides the useState hook for managing state. 

import { useState } from 'react';

const [count, setCount] = useState(0);

This creates two things:

  • count – the current value.
  • setCount – a function used to change the value.
<Button
    title="Add One"
    onPress={() => setCount(count + 1)}
/>

The React process looks like this:

User performs an action
        |
        v
Event Handler Executes
        |
        v
State Changes
        |
        v
React Re-renders Component
        |
        v
Updated Screen

4. Props vs. State

Props State
Passed into a component Managed by the component
Usually supplied by a parent Changes while the application runs
Read-only Can be updated
Helps create reusable components Makes applications interactive

5. User Input with TextInput

Mobile applications frequently need to collect information from users. React Native provides the TextInput component. 

const [name, setName] = useState('');

<TextInput
    placeholder="Enter your name"
    value={name}
    onChangeText={setName}
/>

<Text>
    Hello, {name}!
</Text>

6. Event Handling

Events allow an application to respond to actions performed by the user.

Common React Native events include:

  • onPress
  • onChangeText
const [message, setMessage] = useState('');

<Button
    title="Click Me"
    onPress={() => setMessage('The button was pressed!')}
/>

<Text>
    {message}
</Text>

7. Conditional Rendering

Conditional rendering allows the application to display different information depending on the application's current state. 

const [loggedIn, setLoggedIn] = useState(false);

return (

    <View>

        {loggedIn ? (
            <Text>Welcome back!</Text>
        ) : (
            <Text>Please log in.</Text>
        )}

        <Button
            title={loggedIn ? "Logout" : "Login"}
            onPress={() => setLoggedIn(!loggedIn)}
        />

    </View>

);

Complete Lab Example

import React, { useState } from 'react';

import {
    View,
    Text,
    Button,
    StyleSheet
} from 'react-native';


export default function App() {

    const [bottles, setBottles] = useState(12);


    const addBottle = () => {

        setBottles(bottles + 1);

    };


    const removeBottle = () => {

        if (bottles > 0) {

            setBottles(bottles - 1);

        }

    };


    return (

        <View style={styles.container}>

            <Text style={styles.title}>
                Wine Inventory
            </Text>

            <Text style={styles.wine}>
                Creekside Blanc
            </Text>

            <Text style={styles.count}>
                Bottles Available: {bottles}
            </Text>


            {bottles === 0 && (

                <Text style={styles.outOfStock}>
                    OUT OF STOCK
                </Text>

            )}


            <Button
                title="Add Bottle"
                onPress={addBottle}
            />


            <Button
                title="Remove Bottle"
                onPress={removeBottle}
            />

        </View>

    );

}


const styles = StyleSheet.create({

    container: {

        flex: 1,
        justifyContent: 'center',
        padding: 30

    },

    title: {

        fontSize: 28,
        fontWeight: 'bold',
        marginBottom: 30

    },

    wine: {

        fontSize: 22,
        marginBottom: 10

    },

    count: {

        fontSize: 18,
        marginBottom: 20

    },

    outOfStock: {

        fontSize: 20,
        fontWeight: 'bold',
        marginBottom: 20

    }

});
