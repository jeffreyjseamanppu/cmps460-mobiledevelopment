Module Overview

Most mobile applications contain more than one screen. Think about applications you use every day. A shopping application may have a home screen, product list, product details, shopping cart, account page, and settings page. Social media applications may contain feeds, profiles, messages, notifications, and settings.

In this module, we will move beyond single-screen React Native applications and begin building applications that allow users to move between multiple screens.

We will use React Navigation, a commonly used navigation solution for React Native. Students will learn how to create screens, configure navigation, move between screens, and pass information from one screen to another.

Key Concept: Navigation determines how users move through the different screens and features of a mobile application.

Lecture: Navigation in React Native

1. What Is Navigation?

Navigation is the process of moving between different screens or views within an application.

For example, consider a simple store application:

Home Screen → Products Screen → Product Details Screen

Each screen has a different purpose, but all of the screens work together as part of the same application.

2. Common Types of Mobile Navigation

Stack Navigation

Stack navigation works much like pages being placed on top of one another. When a new screen opens, it is placed on top of the previous screen.

Pressing the back button removes the current screen and returns the user to the previous screen.

Home
  ↓
Products
  ↓
Product Details

Tab Navigation

Tab navigation allows users to switch between major sections of an application using tabs, usually located at the bottom of the screen.

Examples might include:

  • Home
  • Products
  • Favorites
  • Profile

In this module, our primary focus will be Stack Navigation.

3. Installing React Navigation

React Navigation is not automatically included in every React Native project. It must be added to the project.

From the terminal inside your project folder, run:

npm install @react-navigation/native

npm install @react-navigation/native-stack

npx expo install react-native-screens react-native-safe-area-context

After installation, restart the development server if necessary.

4. Creating Screens

As applications become larger, it is helpful to place screens inside their own folder. 

project/
|
|-- App.tsx
|
|-- screens/
    |-- HomeScreen.tsx
    |-- ProductsScreen.tsx
    |-- DetailsScreen.tsx
    |-- AboutScreen.tsx

This makes the application easier to understand and maintain.

5. Creating a Basic Screen

Create a file called HomeScreen.tsx.

import React from 'react';
import { View, Text, Button, StyleSheet } from 'react-native';

export default function HomeScreen({ navigation }: any) {
    return (
        <View style={styles.container}>

            <Text style={styles.title}>
                Welcome to My App
            </Text>

            <Button
                title="View Products"
                onPress={() => navigation.navigate('Products')}
            />

        </View>
    );
}

const styles = StyleSheet.create({

    container: {
        flex: 1,
        justifyContent: 'center',
        alignItems: 'center'
    },

    title: {
        fontSize: 28,
        marginBottom: 20
    }

});

6. Creating the Navigation Stack

The application's navigation structure can be configured in App.tsx. 

import React from 'react';

import {
    NavigationContainer
} from '@react-navigation/native';

import {
    createNativeStackNavigator
} from '@react-navigation/native-stack';

import HomeScreen from './screens/HomeScreen';
import ProductsScreen from './screens/ProductsScreen';
import DetailsScreen from './screens/DetailsScreen';
import AboutScreen from './screens/AboutScreen';

const Stack = createNativeStackNavigator();

export default function App() {

    return (

        <NavigationContainer>

            <Stack.Navigator initialRouteName="Home">

                <Stack.Screen
                    name="Home"
                    component={HomeScreen}
                />

                <Stack.Screen
                    name="Products"
                    component={ProductsScreen}
                />

                <Stack.Screen
                    name="Details"
                    component={DetailsScreen}
                />

                <Stack.Screen
                    name="About"
                    component={AboutScreen}
                />

            </Stack.Navigator>

        </NavigationContainer>

    );
}

7. Navigating Between Screens

The navigation.navigate() function can be used to open another screen. 

navigation.navigate('Products');

It can be connected to a button:

<Button
    title="View Products"
    onPress={() => navigation.navigate('Products')}
/>

8. Passing Data Between Screens

Frequently, one screen needs to send information to another screen.

For example, when a user selects a product, we may want to send the product name and price to the Product Details screen. 

navigation.navigate('Details', {
    productName: 'Wireless Headphones',
    price: 79.99
});

9. Receiving Data

The destination screen receives the information through the route object.

export default function DetailsScreen({ route }: any) {

    const { productName, price } = route.params;

    return (

        <View>

            <Text>
                {productName}
            </Text>

            <Text>
                ${price}
            </Text>

        </View>

    );
}

10. Why Navigation Matters

Good navigation should make an application feel natural and predictable. Users should always understand where they are and how to move to another part of the application.

Good mobile navigation should be:

  • Simple
  • Consistent
  • Predictable
  • Easy to understand
  • Designed around the user's tasks
