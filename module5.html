Module 5: Working with Data, Lists & Local Storage

Module Overview

In the previous modules, you learned how to create React Native applications, build reusable components, manage application state, respond to user interaction, and navigate between multiple screens. In this module, we will take the next step by learning how mobile applications work with collections of data.

Most mobile applications need to manage information. A shopping application might maintain a list of products, a fitness application might track workouts, and a task management application might store a list of tasks. React Native provides tools such as FlatList for efficiently displaying collections of information.

We will also introduce local data persistence. Until now, information stored in application state disappears when the application is closed or restarted. Using AsyncStorage, we can save information on the device and retrieve it when the application starts again.

Learning Objectives

After completing this module, you should be able to:

  • Work with arrays and objects in TypeScript.
  • Store collections of application data using React state.
  • Display collections of data using the React Native FlatList component.
  • Add and remove items from a collection.
  • Use unique identifiers and keys when displaying list data.
  • Pass data between application screens.
  • Understand the difference between temporary application state and persistent data.
  • Save application data locally using AsyncStorage.
  • Retrieve saved information when an application starts.
  • Use JSON.stringify() and JSON.parse() when storing structured data.

Learning Resources

1. Working with Arrays and Objects

Before working with lists in React Native, it is important to understand how JavaScript and TypeScript represent collections of information. 


const tasks = [
    {
        id: "1",
        title: "Complete Mobile Programming Lab",
        completed: false
    },
    {
        id: "2",
        title: "Study React Native",
        completed: true
    }
];

Each object represents one task, while the array represents the entire collection of tasks.

2. Displaying Data with FlatList

React Native provides the FlatList component for displaying lists of information. FlatList is preferred over manually creating large collections of components because it is optimized for mobile applications. 


<FlatList
    data={tasks}
    keyExtractor={(item) => item.id}
    renderItem={({ item }) => (
        <Text>{item.title}</Text>
    )}
/>

The data property identifies the collection to display. The renderItem property determines how each item appears, and keyExtractor provides React with a unique identifier for each item.

3. Managing a Collection with State

Collections can be stored in application state using the useState hook. 


const [tasks, setTasks] = useState<Task[]>([]);

A new task can be added by creating a new array:


setTasks([
    ...tasks,
    {
        id: Date.now().toString(),
        title: taskName,
        completed: false
    }
]);

Remember that React state should not be modified directly. Instead, create a new array containing the updated information.

4. Removing Items

The JavaScript filter() method is commonly used to remove an item from a collection. 


const deleteTask = (id: string) => {
    setTasks(tasks.filter(task => task.id !== id));
};

5. Temporary vs. Persistent Data

React state is temporary. If you store information using useState and restart the application, the information will normally disappear.

Many applications need information to remain available between sessions. Examples include:

  • User preferences
  • Shopping lists
  • Favorite items
  • Notes
  • Tasks
  • Application settings

For this module, we will use AsyncStorage to introduce persistent local storage.

6. AsyncStorage

AsyncStorage provides a simple key-value storage system that allows information to be saved on the mobile device.

Install AsyncStorage in your Expo project:


npx expo install @react-native-async-storage/async-storage

Import AsyncStorage:


import AsyncStorage from '@react-native-async-storage/async-storage';

7. Saving Data

AsyncStorage stores strings. Arrays and objects therefore need to be converted to JSON before they are saved. 


const saveTasks = async (tasks: Task[]) => {
    try {
        await AsyncStorage.setItem(
            "tasks",
            JSON.stringify(tasks)
        );
    } catch (error) {
        console.log("Error saving tasks:", error);
    }
};

8. Loading Data

When retrieving information, the stored JSON string can be converted back into an array or object using JSON.parse(). 


const loadTasks = async () => {
    try {
        const savedTasks = await AsyncStorage.getItem("tasks");

        if (savedTasks !== null) {
            setTasks(JSON.parse(savedTasks));
        }
    } catch (error) {
        console.log("Error loading tasks:", error);
    }
};

This method can be called when the application first loads so previously saved information is restored.

In this lab, you will create a simple Task Tracker application that combines concepts from previous modules with the new data management concepts introduced in Module 5.

Requirements

Your application should contain at least two screens:

  • Task List Screen – Displays the current tasks.
  • Add Task Screen – Allows the user to enter a new task.

interface Task {
    id: string;
    title: string;
    completed: boolean;
}

No tasks have been added. Add your first task!

Part 5 – Persistent Storage

Use AsyncStorage to save the task collection whenever it changes. When the application starts, load the previously saved tasks.
