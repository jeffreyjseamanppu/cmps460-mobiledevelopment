Module: API Integration and Local Data Storage

Fetch remote data, manage loading states, and persist favorites on a mobile device.

Module Overview

Modern mobile apps frequently combine remote data from web APIs with information saved on the user's device. In this module, students create an NFL Teams & Players app that retrieves team information from a sample API and lets users save favorite teams locally.

Suggested duration: 1 week • Prerequisites: React Native components, props, state, basic navigation, JavaScript async functions.

Learning Objectives

  1. Explain APIs, JSON, HTTP GET requests, and asynchronous data retrieval.
  2. Use fetch() and useEffect() in React Native.
  3. Display remote data with FlatList and handle loading and error states.
  4. Store and retrieve JSON data using Expo-compatible AsyncStorage.
  5. Discuss mobile privacy, offline behavior, and secure API practices.

Lesson 1: Understanding APIs and JSON

An API allows a mobile app to request data from another application. A REST-style API often responds with JSON. A GET request retrieves information without changing server-side data.

Example API Response

{
  "teams": [
    { "id": "PIT", "name": "Pittsburgh Steelers", "city": "Pittsburgh", "conference": "AFC" },
    { "id": "PHI", "name": "Philadelphia Eagles", "city": "Philadelphia", "conference": "NFC" },
    { "id": "BUF", "name": "Buffalo Bills", "city": "Buffalo", "conference": "AFC" }
  ]
}

In a production application, this JSON would come from an HTTP endpoint. In this module, students first use a local JSON file so the exercise works without an API account or paid subscription.

Lesson 3: Display NFL Teams

The following starter app loads the sample JSON and displays it in a scrollable list. The simulated asynchronous operation lets students practice the same loading-state pattern used with real APIs.

import React, { useEffect, useState } from 'react';
import { ActivityIndicator, FlatList, SafeAreaView,
  StyleSheet, Text, View } from 'react-native';
import sampleData from './data/teams.json';

export default function App() {
  const [teams, setTeams] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    async function loadTeams() {
      try {
        setTeams(sampleData.teams);
      } finally {
        setLoading(false);
      }
    }
    loadTeams();
  }, []);

  if (loading) return <ActivityIndicator size="large" />;

  return (
    <SafeAreaView style={styles.container}>
      <Text style={styles.heading}>NFL Teams</Text>
      <FlatList
        data={teams}
        keyExtractor={(team) => team.id}
        renderItem={({ item }) => (
          <View style={styles.card}>
            <Text style={styles.team}>{item.name}</Text>
            <Text>{item.city} • {item.conference}</Text>
          </View>
        )}
      />
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 20, paddingTop: 55 },
  heading: { fontSize: 28, fontWeight: 'bold', marginBottom: 16 },
  card: { padding: 16, backgroundColor: '#eaf1f8',
    borderRadius: 10, marginBottom: 10 },
  team: { fontSize: 18, fontWeight: '600' }
});

Lesson 4: Replace Local JSON with an API

Once the starter app works, students can switch to an instructor-provided API endpoint that returns the same { "teams": [...] } structure. Replace the loadTeams function and add an error state:

const [error, setError] = useState('');

async function loadTeams() {
  setLoading(true);
  setError('');
  try {
    const response = await fetch('https://YOUR-API.example/teams');
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    const data = await response.json();
    if (!Array.isArray(data.teams)) {
      throw new Error('Invalid API response');
    }
    setTeams(data.teams);
  } catch (err) {
    setError(err.message);
  } finally {
    setLoading(false);
  }
}

Then add the following before the main return statement:

if (loading) return <ActivityIndicator size="large" />;
if (error) return <Text accessibilityRole="alert">Error: {error}</Text>;

Important: The URL is a placeholder, not a live API. Use an instructor-hosted endpoint or another documented JSON endpoint that permits educational use. Do not put private API keys in mobile app source code.

Lesson 5: Save Favorite Teams with AsyncStorage

Add these imports:

import AsyncStorage from '@react-native-async-storage/async-storage';
import { Button } from 'react-native';

Inside App(), add the following state and functions:

const [favorites, setFavorites] = useState([]);

useEffect(() => {
  async function restoreFavorites() {
    try {
      const saved = await AsyncStorage.getItem('favoriteTeams');
      if (saved) setFavorites(JSON.parse(saved));
    } catch (err) {
      console.warn('Could not restore favorites', err);
    }
  }
  restoreFavorites();
}, []);

async function toggleFavorite(id) {
  const next = favorites.includes(id)
    ? favorites.filter((value) => value !== id)
    : [...favorites, id];
  try {
    await AsyncStorage.setItem('favoriteTeams', JSON.stringify(next));
    setFavorites(next);
  } catch (err) {
    console.warn('Could not save favorites', err);
  }
}

Inside the existing renderItem card, after the team details, add:

<Button
  title={favorites.includes(item.id) ? 'Remove Favorite' : 'Add Favorite'}
  onPress={() => toggleFavorite(item.id)}
/>

Close and reopen the app to verify favorites persist. This is a learning example; production apps should also consider concurrent updates, validation of stored data, and better user-facing error messages.
